# Options du Jeu

Le menu **OPTIONS DU JEU** s'ouvre depuis la [Vue Jeux](system-view-and-game-view.md#vue-jeux) en **maintenant le bouton Sud** ![](<../.gitbook/assets/image (285).png>) sur un jeu.

<div align="left"><figure><img src="../.gitbook/assets/image (286).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Si l'option **ACCÉDER AUX OPTIONS DU JEUX AVEC LE BOUTON NORD** est activée (**MENU PRINCIPAL** > **PARAMÈTRES SYSTÈME** > **OPTIONS DÉVELOPPEUR**), appuyez sur **Nord** à la place.
{% endhint %}

Le menu n'affiche que les entrées disponibles pour le jeu sélectionné.

### Configuration avancée du jeu

<div align="left"><figure><img src="../.gitbook/assets/image (287).png" alt=""><figcaption></figcaption></figure></div>

Ce menu contient les mêmes réglages que la [CONFIGURATION AVANCÉE DU SYSTÈME](view-options.md#configuration-avancee-du-systeme), mais ils ne s'appliquent qu'au jeu sélectionné. Utilisez-le quand un jeu a besoin d'un autre émulateur ou d'un réglage particulier pour fonctionner correctement.

{% hint style="info" %}
* Les réglages du jeu priment sur ceux du système, qui priment sur les réglages généraux (**MENU PRINCIPAL** > **PARAMÈTRES DES JEUX**).
* **AUTO** signifie que le réglage défini pour le système est utilisé.
* Raccourci : appuyez sur **Nord** dans le menu Options du jeu pour ouvrir directement la **CONFIGURATION AVANCÉE DU JEU**.
{% endhint %}

{% hint style="warning" %}
En mode **Enfant** ou **Kiosque**, **SUPPRIMER LE JEU** et les groupes **COLLECTIONS** et **OPTIONS** ne sont pas affichés.
{% endhint %}
