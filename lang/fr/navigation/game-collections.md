# Collections

Les collections permettent de parcourir vos jeux autrement que « un système à la fois » : tous vos favoris, tous les jeux à 2 joueurs, tous vos jeux Mario…

Les collections apparaissent dans la [Vue Systèmes](system-view-and-game-view.md#vue-systemes), comme les systèmes.

Il existe trois types de collections :

<table><thead><tr><th width="139.5">Type</th><th width="380.25">Contenu</th><th>Créée par</th></tr></thead><tbody><tr><td><strong>Automatique</strong></td><td>Jeux sélectionnés automatiquement par RetroBat (favoris, derniers joués, arcade…)</td><td>RetroBat : il suffit d'activer celles que vous voulez</td></tr><tr><td><strong>Éditable</strong></td><td>Les jeux que vous ajoutez vous-même, un par un</td><td>Vous</td></tr><tr><td><strong>Dynamique</strong></td><td>Tous les jeux qui correspondent à des filtres que vous définissez (genre, nombre de joueurs, année…), mise à jour automatiquement</td><td>Vous</td></tr></tbody></table>

Toutes les collections se gèrent dans **MENU PRINCIPAL** > **PARAMÈTRES DES COLLECTIONS** :

### Par genre

Une collection par genre de jeu (action, plateforme, course, shoot'em up…).

### Systèmes d'arcade

Une collection par système d'arcade (CPS-1, CPS-2, Neo Geo, Naomi…). Seuls les systèmes d'arcade pour lesquels vous avez des jeux sont proposés.

{% hint style="info" %}
La plupart des collections automatiques utilisent les **informations des jeux** : nombre de joueurs, genre, système d'arcade… Scrapez d'abord vos jeux pour que ces collections soient complètes (voir [Scrape & Métadonnées](scraping-and-metadata.md)).
{% endhint %}

## Collections éditables

Vous choisissez un par un les jeux d'une collection éditable.

### Créer une collection éditable

1. Dans **PARAMÈTRES DES COLLECTIONS**, sélectionnez **NOUVELLE COLLECTION ÉDITABLE** :

<div align="left"><figure><img src="../.gitbook/assets/image (311).png" alt=""><figcaption></figcaption></figure></div>

2. Saisissez un nom et validez :

<div align="left"><figure><img src="../.gitbook/assets/image (312).png" alt=""><figcaption></figcaption></figure></div>

La collection apparaît dans la Vue Systèmes, seule ou dans le dossier **COLLECTIONS** (voir [Où apparaissent mes collections ?](game-collections.md#ou-apparaissent-mes-collections)) :

<div align="left"><figure><img src="../.gitbook/assets/image (313).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (314).png" alt=""><figcaption></figcaption></figure></div>

### Ajouter un jeu

Dans la Vue Jeux de n'importe quel système, maintenez **Sud** ![](<../.gitbook/assets/image (315).png>) sur un jeu pour ouvrir les [Options du jeu](game-options.md), puis choisissez la collection dans le groupe **COLLECTIONS** (**AJOUTER À JEUX MARIO**, ou **AJOUTER À UNE COLLECTION…** si vous avez plusieurs collections) :

<div align="left"><figure><img src="../.gitbook/assets/image (316).png" alt=""><figcaption></figcaption></figure></div>

Le jeu apparaît maintenant dans la collection :

<div align="left"><figure><img src="../.gitbook/assets/image (317).png" alt=""><figcaption></figcaption></figure></div>

### Retirer un jeu

Ouvrez les Options du jeu et choisissez **SUPPRIMER DE** suivi du nom de la collection.

<div align="left"><figure><img src="../.gitbook/assets/image (318).png" alt=""><figcaption></figcaption></figure></div>

## Collections dynamiques

Une collection dynamique contient tous les jeux qui correspondent aux filtres que vous avez définis. Elle se met à jour automatiquement : quand vous ajoutez un jeu qui correspond aux filtres, il apparaît dans la collection.

### Créer une collection dynamique

1. Dans **PARAMÈTRES DES COLLECTIONS**, sélectionnez **NOUVELLE COLLECTION DYNAMIQUE** :

<div align="left"><figure><img src="../.gitbook/assets/image (319).png" alt=""><figcaption></figcaption></figure></div>

2. Saisissez un nom et validez :

<div align="left"><figure><img src="../.gitbook/assets/image (320).png" alt=""><figcaption></figcaption></figure></div>

3. La liste des filtres s'affiche :

<div align="left"><figure><img src="../.gitbook/assets/image (321).png" alt=""><figcaption></figcaption></figure></div>

4. Choisissez les filtres voulus (par exemple **MEDIA MANQUANTS** pour lister les jeux sans médias), puis revenez en arrière avec **RETOUR** :

<div align="left"><figure><img src="../.gitbook/assets/image (322).png" alt=""><figcaption></figcaption></figure></div>

La collection est créée avec les filtres choisis :

<div align="left"><figure><img src="../.gitbook/assets/image (323).png" alt=""><figcaption></figcaption></figure></div>

### Filtres disponibles

<table><thead><tr><th width="329">Filtre</th><th>Garde les jeux…</th></tr></thead><tbody><tr><td><strong>RECHERCHER DES JEUX</strong></td><td>dont le nom contient un texte</td></tr><tr><td><strong>SYSTÈMES</strong></td><td>des systèmes choisis</td></tr><tr><td><strong>FAVORIS</strong></td><td>marqués (ou non) comme favoris</td></tr><tr><td><strong>GENRE</strong>, <strong>FAMILLE</strong>, <strong>BALISE</strong></td><td>d'un genre, d'une famille de jeux ou avec une balise</td></tr><tr><td><strong>JOUEURS</strong></td><td>pour un nombre de joueurs</td></tr><tr><td><strong>ÉDITEUR/DÉVELOPPEUR</strong>, <strong>ANNÉE</strong>, <strong>NOTATION</strong></td><td>d'un éditeur ou développeur, d'une année, avec une note</td></tr><tr><td><strong>RÉGION</strong>, <strong>LANGUE</strong></td><td>d'une région ou d'une langue</td></tr><tr><td><strong>DÉJÀ JOUÉ</strong></td><td>déjà joués (ou jamais joués)</td></tr><tr><td><strong>JEU ENFANT</strong></td><td>marqués comme jeux pour enfants</td></tr><tr><td><strong>AVEC DES SUCCÈS</strong></td><td>avec des RetroAchievements</td></tr><tr><td><strong>MEDIAS MANQUANTS</strong>, <strong>AYANT DES MÉDIAS</strong></td><td>sans ou avec médias</td></tr><tr><td><strong>PISTOLET OPTIQUE</strong>, <strong>VOLANT</strong>, <strong>TRACKBALL</strong>, <strong>SPINNER</strong>, <strong>VERTICAL</strong></td><td>pour ces contrôleurs, ou à écran vertical</td></tr></tbody></table>

{% hint style="info" %}
**Plus rapide :** dans la Vue Jeux d'un système, appliquez des filtres avec **SELECT** > **AUTRES FILTRES**, puis choisissez **NOUVELLE COLLECTION DYNAMIQUE** dans ce même menu : la collection est créée avec ces filtres.
{% endhint %}

### Modifier les filtres

Ouvrez la collection dynamique, appuyez sur **SELECT** et choisissez **ÉDITER LES FILTRES DE LA COLLECTION**.

## Où apparaissent mes collections ?

Les collections éditables et dynamiques apparaissent soit individuellement dans la Vue Systèmes, soit dans un dossier **COLLECTIONS**. C'est l'option **PARAMÈTRES DES COLLECTIONS** > **REGROUPER LES COLLECTIONS PERSONNALISÉES** qui le détermine :

<table><thead><tr><th width="236.5">Valeur</th><th>Comportement</th></tr></thead><tbody><tr><td><strong>SANS THÈME</strong> (par défaut)</td><td>Les collections qui ont un design dans le thème apparaissent individuellement ; les autres sont regroupées dans <strong>COLLECTIONS</strong></td></tr><tr><td><strong>ALWAYS</strong></td><td>Toutes vos collections sont regroupées dans <strong>COLLECTIONS</strong></td></tr><tr><td><strong>NEVER</strong></td><td>Toutes vos collections apparaissent individuellement</td></tr></tbody></table>

{% hint style="info" %}
**CRÉER DEPUIS LE THÈME** (dans **PARAMÈTRES DES COLLECTIONS** > **CRÉER UNE COLLECTION PERSONNALISÉE**) liste les noms de collections pour lesquels votre thème a un design (logo, fond…). Une collection créée ainsi s'affiche avec ces visuels.
{% endhint %}

## Gérer vos collections

<table><thead><tr><th width="282.75">Je veux…</th><th>Comment</th></tr></thead><tbody><tr><td>Masquer une collection sans la supprimer</td><td><strong>PARAMÈTRES DES COLLECTIONS</strong> > <strong>COLLECTIONS PERSONNALISÉES</strong> : décochez-la</td></tr><tr><td>Supprimer une collection</td><td>Ouvrez la collection, appuyez sur <strong>SELECT</strong> (ou maintenez <strong>Sud</strong> sur un jeu) > <strong>SUPPRIMER LA COLLECTION</strong></td></tr><tr><td>Afficher le système de chaque jeu dans les collections</td><td><strong>PARAMÈTRES DES COLLECTIONS</strong> > <strong>AFFICHER LE NOM DU SYSTÈME DANS LES COLLECTIONS</strong></td></tr><tr><td>Afficher dans les collections les jeux des systèmes masqués</td><td><strong>PARAMÈTRES DES COLLECTIONS</strong> > <strong>AFFICHER LES JEUX DES SYSTÈMES CACHÉS DANS LES COLLECTIONS</strong></td></tr><tr><td>Trier les collections avec les systèmes</td><td><strong>PARAMÈTRES DES COLLECTIONS</strong> > <strong>SORT CUSTOM COLLECTIONS AND SYSTEMS</strong></td></tr></tbody></table>

{% hint style="info" %}
Vos collections sont enregistrées dans `emulationstation\.emulationstation\collections` :

* collections éditables : `custom-<nom>.cfg` (un chemin de jeu par ligne) ;
* collections dynamiques : `<nom>.xcc`.

Sauvegardez ce dossier pour conserver vos collections.
{% endhint %}
