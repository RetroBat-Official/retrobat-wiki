# Navigation

Vous pouvez naviguer dans les écrans et menus de RetroBat avec une manette ou un clavier.

Une notice détaillée au format PDF (`notice_french.pdf`) est également disponible dans votre dossier RetroBat ou ici:

{% embed url="https://github.com/RetroBat-Official/retrobat/blob/main/system/resources/emulationstation/notice_french.pdf" %}

## Manette

Les boutons sont désignés par leur position sur la manette : par exemple, **Sud** est le bouton du bas (B sur Nintendo, ✕ sur PlayStation, A sur Xbox).

| Action                                   | Appui long           | Nintendo             | PlayStation          | Xbox                 |
| ---------------------------------------- | -------------------- | -------------------- | -------------------- | -------------------- |
| Naviguer                                 |                      | Croix / Stick gauche | Croix / Stick gauche | Croix / stick gauche |
| Valider / Lancer un jeu                  | Options du jeu       | B                    | ✕                    | A                    |
| Retour / Annuler                         |                      | A                    | ◯                    | B                    |
| Jeu au hasard / SaveStates               | Ajouter aux favoris  | X                    | △                    | Y                    |
| Rechercher / Filtrer                     | Jeu au hasard        | Y                    | ▢                    | X                    |
| Sélection rapide (défiler dans la liste) |                      | L / R                | L1 / R1              | LB / RB              |
| Système précédent / suivant              |                      | ZL / ZR              | L2 / R2              | LT / RT              |
| Menu principal                           |                      | +                    | START                | Menu (☰)             |
| Accès rapide / Options                   | Afficher les favoris | −                    | SELECT               | Affichage (⧉)        |
| Passer à la musique suivante             |                      | Clic stick gauche    | L3                   | Clic stick gauche    |
