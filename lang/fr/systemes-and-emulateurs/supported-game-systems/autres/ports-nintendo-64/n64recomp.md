## Contrôles

RetroBat n'effectue pas de configuration automatique des contrôles.

## Information spécifique au système

### Ajouter les jeux

Depuis le menu système **RetroBat**, lancer **n64recomplauncher** :

<div align="left"><figure><img src="https://i.imgur.com/VHsBBqC.png" alt=""><figcaption></figcaption></figure></div>

Depuis le lanceur, installer le jeu désiré en cliquant sur la flèche de téléchargement :

<div align="left"><figure><img src="https://i.imgur.com/9ASSZlh.png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="https://i.imgur.com/gJY1Yzc.png" alt=""><figcaption></figcaption></figure></div>

Lancer le jeu et sélectionner l'emplacement du fichier nécessaire à son fonctionnement :

<div align="left"><figure><img src="https://i.imgur.com/4ruFRHV.png" alt=""><figcaption></figcaption></figure></div>

Une fois la version correcte du jeu sélectionnée, le menu affiche "Start Game":

<div align="left"><figure><img src="https://i.imgur.com/kdSlzik.png" alt=""><figcaption></figcaption></figure></div>

Continuer ensuite avec des réglages complémentaires pour le jeu, ou bien quitter celui-ci.

L'étape suivante consiste a créer le raccourci depuis le lanceur :

<div align="left"><figure><img src="https://i.imgur.com/LcHG0iQ.png" alt=""><figcaption></figcaption></figure></div>

Une fois le raccourci crée : quitter le lanceur, puis déplacer le raccourci crée sur votre bureau vers le dossier `\roms\n64recomp` de l'installation RetroBat :

<div align="left"><figure><img src="https://i.imgur.com/a4FQney.png" alt=""><figcaption></figcaption></figure></div>

Actualiser la liste de jeu ou redémarrer RetroBat pour que les jeux apparaissent dans le menu système N64Recomp.

<div align="left"><figure><img src="https://i.imgur.com/wSOR9EI.png" alt=""><figcaption></figcaption></figure></div>



### Scan automatique des jeux

Il est également possible de télécharger et de configurer différent projets de recompilation, et laisser RetroBat scanner les projets installés.

Cette option de scan automatique peut être activée depuis le menu principal PARAMÈTRES DES JEUX  > GAME STORES AND LAUNCHERS > SCAN N64 RECOMPILATION :

<figure><img src="../../../../.gitbook/assets/image (160).png" alt=""><figcaption></figcaption></figure>

Cela permett le scan automatique du dossier `\emulators\n64recomplauncher` au démarrage de RetroBat et la création des raccourcis pour les jeux installés :

<div align="left"><figure><img src="https://i.imgur.com/1cyt6IQ.png" alt=""><figcaption></figcaption></figure></div>
