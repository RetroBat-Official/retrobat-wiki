# Cave Story

<div align="left"><figure><img src="../../../.gitbook/assets/image (681).png" alt="" width="563"><figcaption></figcaption></figure></div>

## Présentation

**Cave Story** (Studio Pixel, 2004) est un jeu d'action et d'exploration en 2D, créé seul par Daisuke Amaya. Le jeu d'origine est gratuit.

RetroBat le lance avec deux cores libretro : **nxengine** (par défaut) et **doukutsu\_rs**.

## Quel émulateur choisir ?

| Émulateur                       | Points forts                                                 | Limites                  |
| ------------------------------- | ------------------------------------------------------------ | ------------------------ |
| **libretro: nxengine** (défaut) | Moteur de référence du jeu d'origine.                        | Jeu d'origine seulement. |
| **libretro: doukutsu\_rs**      | Moteur moderne : écran large, résolution interne jusqu'à x4. |                          |

## Installer le jeu

Téléchargez le jeu depuis le menu [**TÉLÉCHARGEMENT DE CONTENU**](../../../utilisation-avancee/updates-and-content-download.md#telechargement-de-contenu) de RetroBat, ou depuis le site :

{% embed url="https://www.cavestory.org/download/cave-story.php" %}

Deux façons de lancer le jeu :

| Fichier lancé                                         | Effet                                                                                                        |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `Doukutsu.exe` dans `roms\cavestory\<dossier du jeu>` | Le core choisi lance le jeu de ce dossier.                                                                   |
| `nxengine.libretro` dans `roms\cavestory`             | Le core nxengine est lancé sans fichier : il lance le jeu de `bios\nxengine` (`bios\nxengine\Doukutsu.exe`). |
