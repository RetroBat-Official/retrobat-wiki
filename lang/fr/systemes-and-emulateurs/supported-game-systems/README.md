# Systèmes compatibles

Le tableau ci-dessous liste tous les systèmes disponibles dans RetroBat, tels que définis dans le fichier `es_systems.cfg`.

<table><thead><tr><th width="159">Colonne</th><th>Signification</th></tr></thead><tbody><tr><td><strong>Dossier</strong></td><td>Nom du dossier où copier les jeux, dans le dossier <code>roms</code> de RetroBat (par exemple <code>roms\snes</code>). Cliquez dessus pour ouvrir la page du système.</td></tr><tr><td><strong>Nom</strong></td><td>Nom du système</td></tr><tr><td><strong>Type / fabricant</strong></td><td>Type de système (console de salon, console portable, micro-ordinateur, arcade…) et son fabricant</td></tr></tbody></table>

La page de chaque système indique l'émulateur par défaut et les autres émulateurs disponibles, les formats de fichiers acceptés, les BIOS nécessaires et d'autres informations utiles.

Pour utiliser un autre émulateur, voir [Démarrer un jeu](../../premiers-pas/running-a-game.md).

{% hint style="info" %}
* Seuls les systèmes qui contiennent des jeux s'affichent dans RetroBat. Certains systèmes sont aussi [regroupés](../../navigation/system-view-and-game-view.md#systemes-groupes).
* Pour les jeux d'arcade, lisez d'abord le [Guide Arcade](../arcade-guide.md).
{% endhint %}
