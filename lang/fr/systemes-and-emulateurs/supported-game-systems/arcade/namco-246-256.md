# Namco 246/256

<div align="left"><figure><img src="../../../.gitbook/assets/image (475).png" alt="" width="563"><figcaption></figcaption></figure></div>

## Présentation

Le **Namco System 246** est un système d'arcade sorti par Namco en 2001. Il reprend le matériel de la PlayStation 2 de Sony (modèles arcade « COH-H »), avec quelques ajouts pour l'arcade : une interface JVS pour les commandes de la borne, un dongle de sécurité (une carte mémoire spéciale qui contient le logiciel du jeu) et les données du jeu sur CD, DVD ou disque dur.

Il a été suivi du **System 256**, une révision plus rapide utilisée par des jeux comme _Tekken 5_, et du **System Super 256**, conçu pour _Time Crisis 4_. On parle souvent de **System 2x6** pour désigner l'ensemble.

De nombreux jeux d'arcade célèbres tournaient sur ces systèmes : _Tekken 4_ et _Tekken 5_, _Soulcalibur II_ et _III_, _Time Crisis 3_ et _4_, _Vampire Night_, _Ridge Racer V Arcade Battle_, _Wangan Midnight Maximum Tune_, _Cobra The Arcade_, _Bloody Roar 3_, _Super Dragon Ball Z_, des jeux _Mobile Suit Gundam_ ou la série _Taiko no Tatsujin_.

## BIOS

### Fichiers BIOS

Le BIOS n'est utile qu'à **pcsx2x6**. Copiez-le dans le dossier `bios\pcsx2\bios` de RetroBat.

<table><thead><tr><th width="279">Fichier BIOS</th><th>Système</th></tr></thead><tbody><tr><td>r27v1602f.7d</td><td>System 246</td></tr><tr><td>r27v1602f.8g</td><td>System 256</td></tr></tbody></table>

{% hint style="info" %}
Un seul BIOS suffit. RetroBat vérifie qu'au moins un de ces deux fichiers est présent.
{% endhint %}

### Quel BIOS me faut-il ?

* **r27v1602f.8g** (System 256) est conseillé : il fait tourner les jeux System 256 et les jeux System 246.
* RetroBat choisit le BIOS automatiquement : le BIOS System 246 quand le fichier `.acgame` du jeu indique `platform=246`, le BIOS System 256 sinon. Si le fichier choisi est absent, l'autre est utilisé.
* Pour choisir vous-même, utilisez l'option **FORCER LE FIRMWARE** (sous-menu ÉMULATION) : SYSTEM 246 ou SYSTEM 256.

<div align="left"><figure><img src="../../../.gitbook/assets/image (476).png" alt=""><figcaption></figcaption></figure></div>

* Play! et TeknoParrot n'utilisent pas ces fichiers.

## Quel format pour les jeux ?

### pcsx2x6 : fichiers .acgame

Un jeu d'arcade est composé de plusieurs fichiers : les données du jeu (image du CD, du DVD ou du disque dur), un programme de démarrage (.elf), le dongle de sécurité (.ps2) et les réglages de la machine (sram.bin). Un petit fichier texte **.acgame** indique à pcsx2x6 où les trouver.

Exemple pour un jeu dont l'identifiant est `NM00007` :

```
📁 roms\namco2x6
   📄 SoulCalibur II.acgame
   📂 NM00007
      📄 NM00007.chd      (données du jeu)
      📄 boot.elf         (programme de démarrage)
      📄 sram.bin         (créé au premier lancement s'il est absent)
📁 saves\namco2x6\memcards
   📄 NM00007.ps2         (dongle de sécurité)
```

Contenu de `SoulCalibur II.acgame` :

```ini
[game]
gameid=NM00007
```

Avec les versions récentes de pcsx2x6, le **gameid** est la seule entrée obligatoire : les autres valeurs sont trouvées automatiquement. Vous pouvez quand même les indiquer :

<table><thead><tr><th width="120.75">Section</th><th width="131.75">Entrée</th><th>Description</th></tr></thead><tbody><tr><td>[game]</td><td>name</td><td>Nom du jeu</td></tr><tr><td>[game]</td><td>gameid</td><td>Identifiant du jeu (obligatoire)</td></tr><tr><td>[game]</td><td>platform</td><td><code>246</code>, <code>256</code> ou <code>super256</code> (Time Crisis 4)</td></tr><tr><td>[data]</td><td>subdir</td><td>Sous-dossier du jeu (par défaut : l'identifiant du jeu)</td></tr><tr><td>[data]</td><td>elf</td><td>Programme de démarrage (par défaut : <code>boot.elf</code>)</td></tr><tr><td>[data]</td><td>dongle</td><td>Fichier du dongle dans <code>saves\namco2x6\memcards</code> (par défaut : <code>GAMEID.ps2</code>)</td></tr><tr><td>[data]</td><td>card</td><td>Seconde carte mémoire, uniquement pour le mode Conquête de <em>Soulcalibur II</em></td></tr><tr><td>[data]</td><td>mediasrc</td><td>Fichier des données du jeu (par défaut : <code>GAMEID.chd</code>)</td></tr><tr><td>[data]</td><td>media</td><td><code>CD</code>, <code>DVD</code> ou <code>HDD</code></td></tr><tr><td>[data]</td><td>sram</td><td>Fichier des réglages (par défaut : <code>sram.bin</code>)</td></tr><tr><td>[data]</td><td>256Region</td><td>Région du System 256 (<code>ASIA4</code>, <code>ASIA5</code>, <code>JAPAN</code>), utilisée par Taiko no Tatsujin</td></tr></tbody></table>

{% hint style="info" %}
Les fichiers **.ps2** sont des dumps du dongle de sécurité du jeu, pas des cartes mémoire. pcsx2x6 est fourni avec un script (`utils/arcade_game_template.py`) qui crée un fichier .acgame et un programme de démarrage modèles pour chaque jeu.
{% endhint %}

Toutes ces informations ainsi que d'autres détails sont disponibles sur le site de l'émulateur ci-dessous :

### Play! : fichiers .zip et .m3u

* Copiez le romset du jeu (**.zip**, au format MAME) dans `roms\namco2x6`. Le nom du fichier doit correspondre au profil arcade de Play! (par exemple `tekken4.zip`). Si le jeu utilise une image de disque ou de disque dur (.chd), placez-la dans un sous-dossier qui porte le nom du jeu, comme avec MAME.
* Pour les jeux sans fichier .zip, créez un fichier **.m3u** vide portant le nom du profil arcade de Play!. La liste des profils se trouve dans `emulators\play\arcadedefs`.

### TeknoParrot

Le fichier du jeu doit porter le même nom que le profil TeknoParrot (`emulators\teknoparrot\GameProfiles`). RetroBat lit le profil pour savoir si TeknoParrot doit utiliser Play! ou pcsx2x6. Voir la page TeknoParrot pour l'installation des jeux.

### Disposition arcade (pcsx2x6)

<table><thead><tr><th width="327.75">Commande arcade</th><th>Votre manette</th></tr></thead><tbody><tr><td>Pièce</td><td>SELECT</td></tr><tr><td>Start</td><td>START</td></tr><tr><td>Joystick</td><td>Croix</td></tr><tr><td>Boutons 1 à 4</td><td>OUEST, NORD, SUD, EST</td></tr><tr><td>Test (menu service)</td><td>R3</td></tr><tr><td>Service</td><td>L3</td></tr></tbody></table>

Pour les jeux de combat, les boutons suivent la disposition de la borne : par exemple sur _Tekken_, poing gauche OUEST, poing droit NORD, pied gauche SUD, pied droit EST, et sur _Soulcalibur_, A (horizontal) OUEST, B (vertical) NORD, G (garde) SUD, K (pied) EST. Les jeux de course utilisent R2 pour accélérer, L2 pour freiner et L1/R1 pour changer de vitesse.

Test et Service ne sont actifs que si **ACTIVER LE MENU SERVICE** est activé (sous-menu ÉMULATION).

### Contrôles de Play!

Play! utilise une disposition de manette PlayStation 2. Les mappings spécifiques par jeu sont enregistrés dans `system\resources\inputmapping\play_Arcade.yml` (copiez-le dans `user\inputmapping` pour le personnaliser).

Si vous désactivez **AUTOCONFIGURER LES MANETTES**, Play! utilise le profil de contrôles portant le nom du jeu dans `emulators\play\Play Data Files\inputprofiles` (ou le profil par défaut).

### Pistolets

pcsx2x6 gère 2 pistolets pour _Time Crisis 3_, _Time Crisis 4_, _Vampire Night_ ou _Cobra The Arcade_. Activez **ACTIVER LES PISTOLETS** (sous-menu PISTOLETS).

* Pièces et Start : touches 5/6 et 1/2. Avec une DolphinBar Mayflash, croix gauche = pièce, croix droite = start.
* **BORDURE SINDEN** : bordure pour les pistolets Sinden (activée automatiquement quand un pistolet Sinden est détecté).
* **CIBLE** : curseur de la souris ou cible personnalisée.

### Volants

pcsx2x6 configure automatiquement les volants suivants quand **ACTIVER LES VOLANTS** est activé (sous-menu VOLANTS) : Logitech G29, Logitech G923 (PS), Logitech Driving Force GT, Thrustmaster T300RS (PS3), Moza R5.

* **ACTIVER LE RETOUR DE FORCE** : retour de force.
* **CONVERTISSEUR GEARUP/GEARDOWN VERS GEAR3/GEAR4** : passage séquentiel des vitesses dans les jeux à levier de vitesses.
* **FORCE WHEEL 1 INDEX** : si RetroBat choisit le mauvais volant.

## Guides

### Menu service (mode test)

Les jeux d'arcade se règlent dans leur menu service : jeu gratuit (free play), difficulté, nombre de manches, test des commandes… Activez **ACTIVER LE MENU SERVICE** (sous-menu ÉMULATION), lancez le jeu et appuyez sur R3 (ou 0 sur le clavier). Les réglages sont enregistrés dans le fichier `sram.bin` du jeu.

<div align="left"><figure><img src="../../../.gitbook/assets/image (479).png" alt=""><figcaption></figcaption></figure></div>

### Mode Conquête de Soulcalibur II

Le mode Conquête utilise une seconde carte mémoire. Ajoutez `card=ConquestCard0.conquestcard` dans la section `[data]` du fichier .acgame et placez la carte dans `saves\namco2x6\memcards`. À la première utilisation, ouvrez le menu service et choisissez DATA CLEAR > Clear All, puis quittez en sauvegardant : la carte est formatée au démarrage suivant.

### Améliorer les graphismes

Utilisez **RÉSOLUTION INTERNE** (pcsx2x6 et Play!) pour afficher les jeux en haute définition, ainsi que les options visuelles de PCSX2 (sous-menu RENDU VISUEL).
