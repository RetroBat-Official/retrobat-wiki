## Contrôles

### Play!

Il est possible de créer votre propre profil de touches depuis l'émulateur (pour chaque jeu), puis de le nommer à l'identique du fichier du jeu, pour qu'il soit chargé directement par RetroBat dans play lors du lancement du jeu.

Pour cela, placer le fichier .xml du profil à charger dans le répertoire suivant : `\emulators\play\Play Data Files\inputprofiles`:

<div align="left"><figure><img src="https://i.imgur.com/2F3itrK.png" alt=""><figcaption><p>Exemple d'un profil de touches pour le jeu Bloady Roar 3</p></figcaption></figure></div>

{% hint style="info" %}
S'il n'existe pas de profil de touche pour un jeu, RetroBat configure un profil par défaut (Retrobat.xml) identique à la Playstation 2.
{% endhint %}

## Informations spécifiques au système

### Pcsx2x6: Ajouter des jeux

Dans `roms\namco2x6` placer le fichier .acgame du jeu ainsi que son dossier :

<div align="left"><figure><img src="../../../.gitbook/assets/image (196).png" alt=""><figcaption><p>Exemple avec le jeu Ace Driver 3</p></figcaption></figure></div>

**DOSSIERS :** Chaque dossier de jeu devra comporter les fichiers suivants :

* la rom du jeu (.chd, .bin, .iso)
* le fichier .elf (selon les jeux : proverb.elf ou boot.elf)
* le fichier sram.bin sauvegarde la configuration et les réglages des périphériques de la borne émulée. Si ce fichier est absent, le jeu en génèrera un dès son 1er lancement.

<div align="left"><figure><img src="../../../.gitbook/assets/image (197).png" alt=""><figcaption><p>Exemple avec le dossier du jeu Ace Driver 3</p></figcaption></figure></div>

**FICHIERS .ACGAME :** Chaque fichier .acgame comporte les instructions de fonctionnement pour chaque jeu, vous pouvez les vérifier ou éditer si besoin avec l'éditeur de texte Windows ou un logiciel comme Notepad++.\
\
Le contenu d'un fichier .acgame se décompose ainsi :

**`[game]`**

Cette section contient les informations générales permettant d'identifier le jeu.

* `name` : nom du jeu affiché par l'émulateur.
* `gameid` : identifiant unique du jeu. Cette information est obligatoire.
* `platform` : indique le système arcade émulé : `246`, `256` ou `super256`.

**`[data]`**

Cette section indique quels fichiers utiliser pour lancer le jeu.

* `subdir` : nom du sous-dossier contenant les fichiers du jeu, à l'exception du dongle de sécurité.
* `elf` : fichier exécutable utilisé pour démarrer le jeu : `boot.elf` ou `proverb.elf`.
* `dongle` : nom du fichier contenant les données du dongle de sécurité du jeu.
* `card` : (facultatif) permet de charger une carte mémoire secondaire. Cette option est notamment utilisée pour le mode Conquest de SoulCalibur II. Une ligne précédée de `;` est ignorée par l'émulateur.
* `mediasrc` : nom du fichier contenant les données du jeu (rom).
* `media` : indique le type de média utilisé par le jeu : `CD`, `DVD` ou `HDD`.

<div align="left"><figure><img src="../../../.gitbook/assets/image (199).png" alt=""><figcaption><p>Exemple du contenu du fichier .acgame du jeu Ace Driver 3</p></figcaption></figure></div>

**FICHIERS .PS2 :** Les fichiers .ps2 ne sont pas des cartes mémoires, ce sont des images des dongles de sécurité.

Cependant ils doivent être placés dans `saves\namco2x6\memcards` .

***

Toutes ces informations ainsi que d'autres détails sont disponibles sur le site de l'émulateur ci-dessous :

{% embed url="https://ps2homebrew-arcade.github.io/pcsx2x6/game_config/" %}

### Play!: Faire fonctionner un jeu qui ne possède pas de fichier ZIP

Pour les jeux sans .zip, créer un fichier .m3u nommé comme le nom du profile arcade.

Ces noms peuvent se trouver dans le dossier`emulators\play\arcadedefs`.
