# retrobat.ini

Le fichier `retrobat.ini`, à la racine du dossier RetroBat, active ou désactive des fonctions de RetroBat. La plupart de ces options peuvent aussi être modifiées avec l'outil BatGui.

{% hint style="info" %}
* Modifiez le fichier quand RetroBat est fermé.
* Chaque clé doit rester dans sa section (`[RetroBat]`, `[SplashScreen]` ou `[EmulationStation]`).
* Sauf indication contraire, `0` = désactivé et `1` = activé.
{% endhint %}
