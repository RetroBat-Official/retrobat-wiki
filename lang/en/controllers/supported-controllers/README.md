# Supported Controllers

Most controllers that work with Windows also work with RetroBat: gamepads, arcade sticks, lightguns, steering wheels and keyboard.

RetroBat configures your controllers automatically in the emulators: you only need to configure a controller once in RetroBat (see [Controllers configuration](../controller-configuration.md)).

{% hint style="info" %}
**XInput (Xbox-compatible) controllers are recommended** for the best compatibility: they are recognized the same way by all emulators. Other controllers (PlayStation, Switch Pro, 8BitDo in other modes…) also work, but some emulators may need extra configuration.
{% endhint %}
