## Overview

**C-Dogs SDL** is a top-down shooter, a modern and free version of **Cyberdogs** (1994) and **C-Dogs** (1997). It is played alone or with up to 4 players in co-op or deathmatch, on the same screen.

The game is free and comes with its campaigns.

## Which game format?

Create a text file in `roms\cdogs` and change its extension to `.game`.

## Controls

RetroBat configures the players' controllers. Controls are changed in the game options.

## Options

* **USER INTERFACE > SPLITSCREEN**: NEVER, NORMAL or ALWAYS, with several players.
* **VISUAL RENDERING > GAME ZOOM**: size of the game pixels (2 by default).
* **VISUAL RENDERING > BLOOD AMOUNT**, **PIXEL ASPECT RATIO** (like the DOS game on a 4:3 screen).
