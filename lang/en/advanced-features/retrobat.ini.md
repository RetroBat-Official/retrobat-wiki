# retrobat.ini

The `retrobat.ini` file, in the RetroBat root folder, enables or disables RetroBat features. Most of these options can also be changed with the BatGui tool.

{% hint style="info" %}
* Edit the file while RetroBat is closed.
* Each key must stay in its section (`[RetroBat]`, `[SplashScreen]` or `[EmulationStation]`).
* Unless stated otherwise, `0` = off and `1` = on.
{% endhint %}

## \[RetroBat]

<table><thead><tr><th width="184.5">Key</th><th width="98.5">Default</th><th>Description</th></tr></thead><tbody><tr><td>LanguageDetection</td><td>0</td><td>Detects the Windows language at startup and applies it to the interface and RetroArch.</td></tr><tr><td>ResetConfigMode</td><td>0</td><td>Resets the configuration of EmulationStation and of retrobat.ini at startup. Use with care.</td></tr><tr><td>Autostart</td><td>0</td><td>Starts RetroBat with Windows: 0 = no, 1 = startup folder, 2 = registry.</td></tr><tr><td>AutoStartDelay</td><td>0</td><td>Delay before RetroBat starts automatically with Windows, in milliseconds.</td></tr><tr><td><a href="../controllers/supported-controllers/lightguns/wiimotegun.md">WiimoteGun</a></td><td>0</td><td>Runs WiimoteGun at startup, to use a Wiimote as a gun and to navigate in the interface.</td></tr><tr><td>AppLauncher</td><td>""</td><td>Application to launch with RetroBat (.exe, .bat, .cmd…). Use quotes if the path contains spaces. Add <code>-nowindow</code> at the end to start it without a window, for example <code>AppLauncher="C:\tools\app.exe" -nowindow</code>. For more applications, add <code>AppLauncher2</code>, <code>AppLauncher3</code>… up to <code>AppLauncher20</code>.</td></tr><tr><td>DisableWindowsInterface</td><td>0</td><td>Reduces Windows interference while RetroBat runs: 0 = no, 1 = hides the notifications, 2 = also hides the taskbar and the open folder windows. Everything is restored when RetroBat exits. With 1 or 2, RetroBat.exe stays in memory during the whole session.</td></tr></tbody></table>
