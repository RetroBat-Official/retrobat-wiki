# System View and Game View

All screenshots in this section are taken with the default RetroBat theme, **Carbon** (es-theme-carbon).

## System View

The **System View** is the first screen displayed when RetroBat starts. It lets you browse the systems and collections, and open their game list (**Game View**).

<div align="left"><figure><img src="../.gitbook/assets/image (224).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
By default, only the systems that have games in their `roms` folder are displayed. To display all systems, enable **SHOW EMPTY SYSTEMS** in **MAIN MENU** > **GAME COLLECTION SETTINGS**. In the same menu, **SYSTEMS DISPLAYED** lets you hide the systems you do not want to see.
{% endhint %}

{% hint style="info" %}
Some systems are grouped together: see Grouped systems.
{% endhint %}

### System View buttons

<table><thead><tr><th width="186.5">Button</th><th>Action</th></tr></thead><tbody><tr><td>D-pad left / right</td><td>Previous / next system</td></tr><tr><td>L1 / R1</td><td>Scroll quickly through the systems</td></tr><tr><td>South</td><td>Open the game list of the system</td></tr><tr><td>East</td><td>Navigation bar</td></tr><tr><td>North</td><td>Go to a random system (or <a href="../advanced-features/netplay.md">netplay</a>)</td></tr><tr><td>West</td><td>Quick search / Random system (long press)</td></tr><tr><td>START</td><td><a href="main-menu.md">Main menu</a></td></tr><tr><td>SELECT</td><td>Quick access</td></tr><tr><td>L3 / R3</td><td>Skip to the next song</td></tr></tbody></table>

{% hint style="info" %}
When Netplay is enabled, North opens the Netplay menu instead of going to a random system.
{% endhint %}

### Quick search

Press **West** ![](<../.gitbook/assets/image (225).png>) to open the **QUICK SEARCH**: type part of a game name to find it in all your systems.

<div align="left"><figure><img src="../.gitbook/assets/image (226).png" alt=""><figcaption></figcaption></figure></div>

### Navigation bar

Press **East** ![](<../.gitbook/assets/image (227).png>) to open the **NAVIGATION BAR**. It lets you jump directly to a group of systems. Its content depends on how systems are sorted (**MAIN MENU** > **GAME COLLECTION SETTINGS** > **SORT SYSTEMS**):

* by manufacturer (default): go to a manufacturer;
* alphabetically: go to a letter;
* by hardware type: go to a type of hardware (consoles, handhelds, computers…);
* by release year: go to a decade.

<div align="left"><figure><img src="../.gitbook/assets/image (228).png" alt=""><figcaption></figcaption></figure></div>

### Quick access

Press **SELECT** to open the **QUICK ACCESS** menu.

<div align="left"><figure><img src="../.gitbook/assets/image (229).png" alt=""><figcaption></figcaption></figure></div>

From this menu, you can skip to the next song, launch the screensaver, view the RetroBat user manual, or quit RetroBat.

## Game View

The **Game View** is where you browse the games of a system or a collection, and launch them.

To open it, select a system or a collection in the System View, then press **South** ![](<../.gitbook/assets/image (233).png>) .

### Game list display

The game list can be displayed in different ways (list, grid, detailed view…), depending on the theme. To change it for a system, press **SELECT** to open the [VIEW OPTIONS](https://wiki.retrobat.org/navigation/view-options), then choose a **GAMELIST VIEW STYLE**:

<div align="left"><figure><img src="../.gitbook/assets/image (235).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (236).png" alt=""><figcaption></figcaption></figure></div>

The **AUTOMATIC** value uses the view style defined for all systems. To change it:

1. Press **START** to open the [Main Menu](main-menu.md), and go to **USER INTERFACE SETTINGS**.

<div align="left"><figure><img src="../.gitbook/assets/image (237).png" alt=""><figcaption></figcaption></figure></div>

2. Go to **THEME CONFIGURATION**.

<div align="left"><figure><img src="../.gitbook/assets/image (238).png" alt=""><figcaption></figcaption></figure></div>

3. Set the **GAMELIST VIEW STYLE**.

<div align="left"><figure><img src="../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Each theme offers its own view styles: try them and keep the one you prefer.
{% endhint %}
