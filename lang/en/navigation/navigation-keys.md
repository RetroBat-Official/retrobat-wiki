# Navigation Keys

You can navigate RetroBat with a controller or a keyboard.

A detailed PDF guide (`notice.pdf`) is also available in your RetroBat folder or here:

{% embed url="https://github.com/RetroBat-Official/retrobat/blob/main/system/resources/emulationstation/notice.pdf" %}

## Controller

Buttons are named by their position on the controller: for example, **South** is the bottom face button (B on Nintendo, ✕ on PlayStation, A on Xbox).

| Action                               | Long press       | Nintendo           | PlayStation        | Xbox               |
| ------------------------------------ | ---------------- | ------------------ | ------------------ | ------------------ |
| Navigate                             |                  | D-pad / left stick | D-pad / left stick | D-pad / left stick |
| Validate / Launch a game             | Game options     | B                  | ✕                  | A                  |
| Back / Cancel                        |                  | A                  | ◯                  | B                  |
| Random game / Save snap              | Add to favorites | X                  | △                  | Y                  |
| Search / Filter                      | Random game      | Y                  | ▢                  | X                  |
| Quick select (jump through the list) |                  | L / R              | L1 / R1            | LB / RB            |
| Previous / next system               |                  | ZL / ZR            | L2 / R2            | LT / RT            |
| Main menu                            |                  | +                  | START              | Menu (☰)           |
| Quick access / Options               | Show favorites   | −                  | SELECT             | View (⧉)           |
| Skip to the next song                |                  | Left stick click   | L3                 | Left stick click   |
