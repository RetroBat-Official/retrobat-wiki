# Game Options

The **GAME OPTIONS** menu is opened from the [Game View](system-view-and-game-view.md#game-view) by **holding South** ![](<../.gitbook/assets/image (243).png>) on a game.

<div align="left"><figure><img src="../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
If the **ACCESS GAME OPTIONS WITH NORTH BUTTON** option is enabled (**MAIN MENU** > **SYSTEM SETTINGS** > **FRONTEND DEVELOPER OPTIONS**), press **North** instead.
{% endhint %}

The menu only shows the entries available for the selected game.

### Advanced game options

<div align="left"><figure><img src="../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure></div>

This menu contains the same settings as the [ADVANCED SYSTEM OPTIONS](view-options.md#advanced-system-options), but they only apply to the selected game. Use it when a game needs a different emulator or a specific setting to work correctly.

{% hint style="info" %}
* Game settings override system settings, which override global settings (**MAIN MENU** > **GAME SETTINGS**).
* **AUTO** means that the setting defined for the system is used.
* Shortcut: press **North** in the Game Options menu to open the **ADVANCED GAME OPTIONS** directly.
{% endhint %}

{% hint style="warning" %}
In **Kid** or **Kiosk** mode, **DELETE GAME** and the **COLLECTIONS** and **OPTIONS** groups are not displayed.
{% endhint %}
