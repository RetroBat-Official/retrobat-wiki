# Game Collections

Collections let you browse your games in other ways than "one system at a time": all your favorites, all 2-player games, all your Mario games…

Collections appear in the [System View](system-view-and-game-view.md#system-view), like the systems.

There are three kinds of collections:

<table><thead><tr><th width="134.5">Kind</th><th width="391">Content</th><th>Created by</th></tr></thead><tbody><tr><td><strong>Automatic</strong></td><td>Games selected automatically by RetroBat (favorites, last played, arcade…)</td><td>RetroBat: you just enable the ones you want</td></tr><tr><td><strong>Editable</strong></td><td>The games you add yourself, one by one</td><td>You</td></tr><tr><td><strong>Dynamic</strong></td><td>All games matching filters you define (genre, number of players, year…), updated automatically</td><td>You</td></tr></tbody></table>

All collections are managed in **MAIN MENU** > **GAME COLLECTION SETTINGS**:

Retrobat comes bundled with **AUTOMATIC GAME COLLECTIONS** that you can enable.

You can also create your own game collection, to do this you have 2 options:

* EDITABLE COLLECTION
* DYNAMIC COLLECTION

### Per genre

One collection per game genre (action, platform, racing, shoot'em up…).

### Arcade systems

One collection per arcade system (CPS-1, CPS-2, Neo Geo, Naomi…). Only the arcade systems for which you have games are listed.

{% hint style="info" %}
Most automatic collections use the **game information**: number of players, genre, arcade system… Scrape your games first so that these collections are complete (see [Scraping & Metadata](https://wiki.retrobat.org/navigation/scraping-and-metadata)).
{% endhint %}

## Editable collections

You choose the games of an editable collection one by one.

### Creating an editable collection

1. In **GAME COLLECTION SETTINGS**, select **CREATE NEW EDITABLE COLLECTION**:

<div align="left"><figure><img src="../.gitbook/assets/image (273).png" alt=""><figcaption></figcaption></figure></div>

2. Enter a name and validate:

<div align="left"><figure><img src="../.gitbook/assets/image (274).png" alt=""><figcaption></figcaption></figure></div>

The collection appears in the System View, alone or in the **COLLECTIONS** folder (see [Where do my collections appear?](game-collections.md#where-do-my-collections-appear)):

<div align="left"><figure><img src="../.gitbook/assets/image (275).png" alt=""><figcaption><p>New Collections folder</p></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (276).png" alt=""><figcaption><p>Mario Games collection appears in the Collections folder</p></figcaption></figure></div>

### Adding a game

In the Game View of any system, hold **South** ![](<../.gitbook/assets/image (277).png>) on a game to open the [Game Options](game-options.md), and choose the collection in the **COLLECTIONS** group (**ADD TO MARIO GAMES**, or **ADD TO CUSTOM COLLECTION…** if you have several collections):

<div align="left"><figure><img src="../.gitbook/assets/image (278).png" alt=""><figcaption></figcaption></figure></div>

The game now appears in the collection:

<div align="left"><figure><img src="../.gitbook/assets/image (279).png" alt=""><figcaption></figcaption></figure></div>

### Removing a game

Open the Game Options of the game and choose **REMOVE FROM** followed by the collection name.

<div align="left"><figure><img src="../.gitbook/assets/image (280).png" alt=""><figcaption></figcaption></figure></div>

## Dynamic collections

A dynamic collection contains all the games that match the filters you define. It updates automatically: when you add a game that matches the filters, it appears in the collection.

### Creating a dynamic collection

1. In **GAME COLLECTION SETTINGS**, select **CREATE NEW DYNAMIC COLLECTION**:

<div align="left"><figure><img src="../.gitbook/assets/image (281).png" alt=""><figcaption></figcaption></figure></div>

2. Enter a name and validate:

<div align="left"><figure><img src="../.gitbook/assets/image (282).png" alt=""><figcaption></figcaption></figure></div>

3. The list of filters is displayed:

<div align="left"><figure><img src="../.gitbook/assets/image (283).png" alt=""><figcaption></figcaption></figure></div>

4. Select the filters you want (for example **MISSING MEDIAS** to list the games without the media you expect), then go **BACK**:

<div align="left"><figure><img src="../.gitbook/assets/image (284).png" alt=""><figcaption></figcaption></figure></div>

The collection is created with the selected filters:

<div align="left"><figure><img src="../.gitbook/assets/image (285).png" alt=""><figcaption></figcaption></figure></div>

### Available filters

<table><thead><tr><th width="347.75">Filter</th><th>Keeps the games…</th></tr></thead><tbody><tr><td><strong>FIND GAMES</strong></td><td>whose name contains a text</td></tr><tr><td><strong>SYSTEMS</strong></td><td>of the selected systems</td></tr><tr><td><strong>FAVORITES</strong></td><td>marked (or not) as favorites</td></tr><tr><td><strong>GENRE</strong>, <strong>FAMILY</strong>, <strong>TAG</strong></td><td>of a genre, a game family or with a tag</td></tr><tr><td><strong>PLAYERS</strong></td><td>for a number of players</td></tr><tr><td><strong>PUBLISHER/DEVELOPER</strong>, <strong>YEAR</strong>, <strong>RATING</strong></td><td>from a publisher or developer, a year, with a rating</td></tr><tr><td><strong>REGION</strong>, <strong>LANGUAGE</strong></td><td>of a region or a language</td></tr><tr><td><strong>ALREADY PLAYED</strong></td><td>already played (or never played)</td></tr><tr><td><strong>KIDGAME</strong></td><td>marked as kid games</td></tr><tr><td><strong>HAS ACHIEVEMENTS</strong></td><td>with RetroAchievements</td></tr><tr><td><strong>MISSING MEDIAS</strong>, <strong>HAVING MEDIAS</strong></td><td>without or with media</td></tr><tr><td><strong>LIGHTGUN</strong>, <strong>STEERING WHEEL</strong>, <strong>TRACKBALL</strong>, <strong>SPINNER</strong>, <strong>VERTICAL</strong></td><td>for these controllers, or with a vertical screen</td></tr></tbody></table>

{% hint style="info" %}
**Faster:** in the Game View of a system, apply filters with **SELECT** > **OTHER FILTERS**, then choose **CREATE NEW DYNAMIC COLLECTION** in the same menu: the collection is created with these filters.
{% endhint %}

### Changing the filters

Open the dynamic collection, press **SELECT** and choose **EDIT DYNAMIC COLLECTION FILTERS**.

## Where do my collections appear?

Editable and dynamic collections appear either individually in the System View, or inside a **COLLECTIONS** folder. This is defined by **GAME COLLECTION SETTINGS** > **GROUP CUSTOM COLLECTIONS**:

<table><thead><tr><th width="207.75">Value</th><th>Behavior</th></tr></thead><tbody><tr><td><strong>UNTHEMED</strong> (default)</td><td>Collections that have their own design in the theme appear individually; the others are grouped in <strong>COLLECTIONS</strong></td></tr><tr><td><strong>ALWAYS</strong></td><td>All your collections are grouped in <strong>COLLECTIONS</strong></td></tr><tr><td><strong>NEVER</strong></td><td>All your collections appear individually</td></tr></tbody></table>

{% hint style="info" %}
**CREATE FROM THEME** (in **GAME COLLECTION SETTINGS** > **CREATE CUSTOM COLLECTION**) lists the collection names for which your theme has a design (logo, background…). A collection created this way is displayed with these visuals.
{% endhint %}

## Managing your collections

<table><thead><tr><th width="241.5">I want to…</th><th>How</th></tr></thead><tbody><tr><td>Hide a collection without deleting it</td><td><strong>GAME COLLECTION SETTINGS</strong> > <strong>CUSTOM GAME COLLECTIONS</strong>: untick it</td></tr><tr><td>Delete a collection</td><td>Open the collection, press <strong>SELECT</strong> (or hold <strong>South</strong> on a game) > <strong>DELETE COLLECTION</strong></td></tr><tr><td>Show the system name of each game in collections</td><td><strong>GAME COLLECTION SETTINGS</strong> > <strong>SHOW SYSTEM NAME IN COLLECTIONS</strong></td></tr><tr><td>Show in collections the games of hidden systems</td><td><strong>GAME COLLECTION SETTINGS</strong> > <strong>SHOW GAMES OF HIDDEN SYSTEMS IN COLLECTIONS</strong></td></tr><tr><td>Sort collections with the systems</td><td><strong>GAME COLLECTION SETTINGS</strong> > <strong>SORT CUSTOM COLLECTIONS AND SYSTEMS</strong></td></tr></tbody></table>

{% hint style="info" %}
Your collections are stored in `emulationstation\.emulationstation\collections`:

* editable collections: `custom-<name>.cfg` (one game path per line);
* dynamic collections: `<name>.xcc`.

Back up this folder to keep your collections.
{% endhint %}
